# Mapa de Propagação HF (WebView Flutter Android)

Projeto Flutter configurado com `webview_flutter` para exibir o mapa de propagação HF no Android e compilar o APK via GitHub Actions.

## Como gerar o APK no GitHub

1. Extraia o conteúdo deste ZIP.
2. Envie todos os arquivos (incluindo a pasta `.github`) para a raiz do seu repositório no GitHub.
3. Acesse a aba **Actions**, selecione **Build Android APK** e clique em **Run workflow**.
4. Após a conclusão, baixe o artefato `mapa-propagacao-hf-release` com o arquivo `app-release.apk`.
